# Mangosteen for Linux

Zero-click file converter and toolbox for Linux. The Linux sibling of
[Mangosteen](https://github.com/SpaceCadet0/Mangosteen) for macOS and
[Mangosteen for Windows](https://github.com/SpaceCadet0/Mangosteen-Windows).

Work in progress: this repository is being built up phase by phase. A full README follows with the first release.

## Development

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest
```
