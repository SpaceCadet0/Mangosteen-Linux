Collage backgrounds and shadows; every file of a large drag arrives.

- **Collage: gradient background.** Background is now Colour or Gradient, with Start, End and Angle; it starts with
  the same colours and angle as the Background tool and draws the same gradient across the whole canvas.
- **Collage: shadow.** A soft shadow under every photo, 0 by default; shadows never fall on a neighbouring photo.
- **Collage: order in the preview.** Pick up a photo in the preview and drop it on the place of another; the others
  move along as rows do in the list, and the list always shows the same order.
- **Dragging many files.** With dozens of files selected, a file manager may still be writing the list when the drag
  starts, so a few could go missing (58 of 60). The list is read again at the key tap and taken from the drop itself;
  the longer one wins.

Update with **Check for Updates…** in the tray menu or in About Mangosteen.

**Download:** `Mangosteen-0.2.2-x86_64.AppImage` or `mangosteen_0.2.2_amd64.deb`; for ARM (Raspberry Pi), install from
source — see the README.

Фон и тени в коллаже; при перетаскивании многих файлов доходят все.

- **Коллаж: градиентный фон.** «Фон» — «Цвет» или «Градиент» с «Началом», «Концом» и «Углом»; по умолчанию те же цвета
  и угол, что в инструменте «Фон», и тот же градиент через весь холст.
- **Коллаж: тень.** Мягкая тень под каждым фото, по умолчанию выключена; на соседнее фото тень не ложится.
- **Коллаж: порядок в превью.** Возьмите фото в превью и бросьте на место другого — остальные сдвинутся, как строки в
  списке; список и превью всегда показывают один порядок.
- **Перетаскивание многих файлов.** Когда выделено несколько десятков файлов, файловый менеджер может ещё дописывать
  список в начале перетаскивания, и часть файлов терялась (58 из 60). Теперь список перечитывается при нажатии клавиши
  и берётся из самого броска; используется тот, где файлов больше.

Обновиться можно кнопкой **Проверить обновления…** в меню трея или в окне «О Mangosteen».

исходников, см. README.
