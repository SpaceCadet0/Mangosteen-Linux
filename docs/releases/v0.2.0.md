The first release of Mangosteen for Linux: the zero-click file converter and toolbox from macOS and Windows, built for
Linux desktops.

**Download:** `Mangosteen-0.2.0-x86_64.AppImage` (everything included, FFmpeg too) or `mangosteen_0.2.0_amd64.deb`
(Debian, Ubuntu and derivatives). For ARM, such as a Raspberry Pi, install from source — see the README.

### What it does

- **Three wheels at the pointer.** Start dragging files, tap Shift, Ctrl or Alt without letting go, drop on a segment:
  Convert, Tools or Actions. On Wayland, and without a drag, the tray, the file managers' right-click menus and the
  command line open the same wheels.
- **Convert** images (HEIC and AVIF included), PDF, documents, tables, subtitles, video, audio and archives; the result
  appears next to the original.
- **Tools** with a live preview: crop and resize, photo editor, annotate, hide faces and text, compress, background,
  remove background, collage, metadata, text recognition, PDF split, page order and merge; trim, split, speed,
  volume, channels, bleep, visualizer, reframe, hide areas in a video, join and frames.
- **Actions:** the Float shelf, copy, path, move and terminal.
- **Check for Updates…** in the tray menu and in About Mangosteen installs new versions from the app: the AppImage
  replaces itself, the .deb asks for your password, a copy installed from source is reinstalled.
- English, Spanish and Russian; light and dark themes; works offline.

### Since the first test builds

- The welcome window plays a short video of the three wheels.
- On a Wayland desktop the drag is no longer watched, so it cannot leave a drag hanging in the file manager.
- The wheel redraws only what changes on hover (smooth on a Raspberry Pi), and without a compositor it has no black
  ring around it.
- No sounds: the hover click held up the interface on some audio setups.
- A click on the tray icon opens its menu, with either mouse button.
- Float and the progress window have no black frame without a compositor, and Float's tooltips are readable.
- First launch with `--tool`, `--wheel` or a file manager's menu entry works.
- Text extracted from PDF keeps words and lines together on every system.

Первый выпуск Mangosteen для Linux — конвертер файлов и набор инструментов без лишних кликов, как в версиях для macOS
и Windows.

**Скачать:** `Mangosteen-0.2.0-x86_64.AppImage` (всё внутри, включая FFmpeg) или `mangosteen_0.2.0_amd64.deb` (Debian,
Ubuntu и производные). Для ARM, например Raspberry Pi, — установка из исходников, см. README.

- **Три колеса у курсора:** начните тащить файлы, нажмите Shift, Ctrl или Alt, не отпуская мышь, и бросьте на сегмент.
  В Wayland и без перетаскивания те же колёса открываются из трея, меню файловых менеджеров и командной строки.
- **Конвертация, инструменты с живым предпросмотром и действия** — как в версиях для macOS и Windows; результат
  появляется рядом с оригиналом.
- **Проверить обновления…** в меню трея и в окне «О Mangosteen» — новые версии ставятся прямо из приложения.
- **С первых тестовых сборок:** видео в окне приветствия; в Wayland перетаскивание больше не отслеживается и не
  зависает; колесо быстрое на Raspberry Pi и без чёрного кольца без композитора; звуков больше нет; клик по значку в трее любой кнопкой открывает меню; у Float и окна прогресса нет
  чёрной рамки без композитора; исправлен первый
  запуск с `--tool` и `--wheel`; текст из PDF извлекается целыми словами и строками.
